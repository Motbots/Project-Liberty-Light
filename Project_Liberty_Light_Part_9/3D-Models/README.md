# Project Liberty Light – 3D Display Parts

Welcome to the 3D-printing resources for **Project Liberty Light**, a nine-part electronics project series from **Motbots**.

These models were created for **Part 9: Final Assembly and Display**, where the completed Project Liberty Light electronics are installed into a shadowbox with a custom LED matrix frame and a separate controls enclosure.

The goal of these designs is to provide a clean, organized, and finished appearance for the project while keeping the electronics accessible.

**These 3D-printed components are entirely optional.** You can build and enjoy Project Liberty Light without printing any of these parts, or you can modify the designs to create your own display.

## Included 3D Models

This collection contains three components:

### 1. LED Matrix Frame

A custom frame designed to accommodate the two 8×8 WS2812B LED matrices used to create the American flag display.

The frame helps position the matrices within the shadowbox and provides a cleaner, more finished presentation.

### 2. Controls Box

A separate enclosure designed to attach beneath the shadowbox and house the majority of Project Liberty Light's additional electronics and controls.

This enclosure helps keep the completed display organized while providing a dedicated space for the control components.

### 3. Controls Box Sliding Door

A removable sliding door designed to fit the controls box.

The door allows access to the enclosure's interior for maintenance, adjustments, or future modifications.

## File Organization

The 3D-printing resources are organized into the following directories:

- **STL/** – Individual STL files for all three components. These can be imported into most 3D-printing slicers.
- **Bambu-Studio/** – A combined Bambu Studio 3MF project containing all three components, arranged on separate print plates with their respective printing configurations.
- **Fusion-Source/** – Original editable Autodesk Fusion design files for anyone interested in modifying or adapting the models.

## Printing Information

The original components were prepared in Bambu Studio and printed using a **Bambu Lab P2S** with Bambu PLA Basic filament.

### Print Settings

| Setting | Value |
|---|---|
| Printer | Bambu Lab P2S |
| Nozzle Diameter | 0.4 mm |
| Filament | Bambu PLA Basic |
| Build Plate | Textured PEI Plate |
| Layer Height | 0.12 mm |
| Wall Loops | 4 |
| Infill Density | 80% |
| Infill Pattern | Zig-zag |
| Brim | Auto, 5 mm |

### Print Plates and Supports

| Plate | Component | Supports |
|---|---|---|
| 1 | LED Matrix Frame | None |
| 2 | Controls Box | Manual tree supports, 30° threshold |
| 3 | Controls Box Sliding Door | None |

The included Bambu Studio 3MF project contains all three components with their individual print configurations.

These settings were used for the original Project Liberty Light display. Depending on your printer, filament, and personal preferences, adjustments may be necessary.

**Important:** Review the slicing preview, support placement, and printer compatibility before starting a print.

## Display Compatibility

The original Project Liberty Light display uses:

- Two 8×8 WS2812B LED matrices
- An approximately 8.5 × 11-inch shadowbox
- A shadowbox interior depth of approximately 1.5 inches
- A custom controls box mounted beneath the shadowbox

These designs were created around the components used in my original build. Different shadowboxes, electronics, or hardware may require modifications.

If you're using a different display arrangement, the included Fusion source files can serve as a starting point for customizing the parts.

## About Project Liberty Light

Project Liberty Light began as a patriotic LED display celebrating America's 250th anniversary in 2026.

Throughout the nine-part Motbots series, the project grew from a basic American flag displayed on two LED matrices into a complete interactive display featuring button controls, a dedicated power system, patriotic music, lighting effects, and Celebration Mode.

Although originally created for America's 250th birthday, Liberty Light can be enjoyed during Independence Day, Memorial Day, Veterans Day, and other patriotic celebrations for years to come.
